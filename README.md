# Learn_Java

This repository contains beginner-level Java programs focused on arrays, searching, and basic problem-solving patterns.

## Project Structure

```text
Learn_Java/
├── Arr1.java
├── Arr2.java
├── Arr3.java
├── maxArr.java
├── no_reversal.java
├── README.md
```

## Files Included

- `Arr1.java` — array creation, input, output, and update operations
- `Arr2.java` — linear search, maximum/minimum element, and binary search
- `Arr3.java` — reverse array, pairs, subarrays, and maximum subarray sum
- `maxArr.java` — finds the missing number in a sequence using array logic
- `no_reversal.java` — reverses an integer without using built-in reverse functions

## How to Run

Compile and run any Java file using:

```bash
javac FileName.java
java FileName
```

Example:

```bash
javac Arr1.java
java Arr1
```

## Learning Goal

This folder is intended for Java practice on core array-based concepts and beginner algorithm exercises.
